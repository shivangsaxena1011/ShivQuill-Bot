# QuillBot Product Inventory & Access Tier Analysis

## 1. Executive Summary & Tool Suite Overview

QuillBot provides an integrated web-based suite of writing and editing tools. The ecosystem is organized around a dual-panel text workspace with mode toggles, setting sliders, and context-aware action bars.

| Tool Name | Public / Free Access | Account Required | Subscription Required (Premium) | Key Primary Function |
| :--- | :--- | :--- | :--- | :--- |
| **Paraphraser** | Yes (Capped at 125 words, Standard & Fluency modes) | No | Yes (Unlimited words, 9+ modes, max synonym slider) | Rewrite sentences/paragraphs with configurable style and vocabulary variance |
| **Grammar Checker** | Yes (Free with unlimited checks) | No | Optional (Advanced formatting, tone suggestions) | Spellcheck, punctuation, and grammatical error correction |
| **AI Humanizer** | Limited preview | Yes | Yes (Full word count and restructuring depth) | Refine robotic/stiff syntax into natural, human-flowing prose |
| **Summarizer** | Yes (Capped at 1,200 words) | No | Yes (Up to 6,000 words, custom length) | Condense long documents into paragraph or bullet-point summaries |
| **Translator** | Yes (50+ languages) | No | No (Supported for all users) | Multilingual translation maintaining sentence structure |
| **AI Detector** | Yes (Min 80 words, basic probability) | No | Yes (Detailed segment analysis) | Statistical likelihood analysis of machine-generated text |
| **Plagiarism Checker** | No | Yes | Yes (Quota of 25,000 words/month) | Cross-reference text against web index and academic journals |
| **Citation Generator** | Yes (Free, 1,000+ citation styles) | No | No | Generate APA, MLA, Chicago, Harvard citations from URLs or ISBNs |
| **QuillBot Flow / Co-Writer** | Limited trial | Yes | Yes | Unified editor combining search, citations, notes, and AI generation |
| **AI Chat** | Limited preview | Yes | Yes | Interactive conversational writing assistant |

## 2. Access Tier Restrictions & Limits

### Free Tier (Anonymous / Guest)
- **Paraphraser**: 125-word limit per submit. Only 2 modes accessible: *Standard* and *Fluency*. Synonym slider limited to low/medium intensity (Levels 1–3).
- **Summarizer**: 1,200-word limit per input.
- **Grammar Checker**: Standard error detection.
- **AI Detector**: Supported with word count limits (minimum 80 words).
- **Plagiarism Checker**: Inaccessible (0 words included).

### Free Registered Tier (Authenticated)
- Retains standard word caps but stores limited document history in browser local storage or synced account state.

### Premium Subscription Tier
- **Paraphraser**: Unlimited words per request; all modes unlocked (*Formal*, *Academic*, *Simple*, *Creative*, *Expand*, *Shorten*, *Custom*); Level 4 Synonym slider; faster processing queue.
- **Summarizer**: Up to 6,000 words per input.
- **Plagiarism Checker**: 25,000 words scanned per monthly billing cycle.
- **Tone Insights**: Full sentence-level tone and clarity scoring.
